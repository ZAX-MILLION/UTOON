# UTOON SEO & GEO Strategy

## Principle

SEO is a product/architecture requirement. GEO/AI discoverability is a consequence of clear, crawlable, factual content—not a separate content-spam strategy.

## Index quality gate

A game may be playable without being indexable.

Index only when:
- rights and publication state are valid;
- the game works;
- the page has verified useful value beyond provider boilerplate;
- canonical/metadata are correct;
- internal crawlable links exist;
- the page is not deceptive/thin/duplicative by design.

## First-party value

Examples:
- correct controls;
- how-to-play;
- touch/keyboard/mouse facts;
- orientation;
- verified mobile/desktop notes;
- known issues/troubleshooting;
- last-tested date where permitted;
- meaningful related-game selection.

No arbitrary word-count target. No mass LLM rewriting.

## Technical launch requirements

- server/static-rendered crawlable HTML;
- semantic headings;
- canonical URL;
- robots policy;
- XML sitemap containing intended indexable pages only;
- crawlable `<a href>` internal links;
- valid structured data only for facts we truly support;
- OG/Twitter metadata;
- Search Console;
- production/staging indexation separation.

## Performance

Do not sacrifice Core Web Vitals to decorative JS, autoplay media, or early iframe loading.

## AI discovery

Use clear entity names, semantic HTML, factual page sections, structured relationships, and stable URLs. Do not create pages primarily for answer engines.

## Measurement

Use Search Console by page/template/query:
- discovered/crawled/indexed/excluded;
- impressions/clicks;
- query patterns;
- page groups.

Do not promise indexing time or rankings.

## Arabic

Architecture is RTL/locale-ready. Arabic pages are expanded only after small-scale native-quality tests show both discoverability and acceptable economics.
